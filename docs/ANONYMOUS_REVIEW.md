# Anonymous publication artifact

Personal usernames in published paths are anonymized. The public scope is defined by `provenance/paper_scope.json` and does not represent the complete research history. Full original source records are kept in the author archive. This release preserves every included numerical observation, the numerical core and environment locks.

Derived dispatch configurations and published result projections carry their own fingerprints. A raw server file fingerprint and its anonymized/published-view fingerprint are separate values. Archived orchestration source is never executed as a historical controller; fresh working-directory bindings are explicit and logged.
