# 已知限制

本文解释收录结果，不修改历史分数。

- **资格**：研究prior回退的输出仍可评分，但不是合格部署技能。资格、源内拟合和正式修复质量分开报告。
- **候选缺失**：三类新错误是新测试条件/组合，未证明旧模板绝对不可达。原排序/接受式LLM不能在候选缺失时任意生成真值。零分、相同和反向结果保留。
- **污染分母**：数字70%直接抽可污染已知特征格；新错误每区每字段抽30%合格格；旧单类鲁棒性名义30%沿四类配额，实际约7.5%—7.6%。不能混称同强度。
- **展示选择**：代表性消融两表和真实错误五表来自既有结果选择，完整六表/八表保留。不称三/五种子统计显著。
- **Movies / Raha + HoloClean**：输出真实存在，三种子准确修复1、2、0格。Raha标记大量带逗号计数，源内无满足条件的FD，候选域难以产生去逗号新值；另有正常空值被填充。原生strip/lowercase与输出适配有大小写往返限制，极低分不能只解释为检测失败或一般算法无效。
- **Movies / CDC（CPU兼容）**：准确修复15、22、27格，正常格损伤高。16列按类别处理，高基数名称/描述的校准值大量不在训练类别中，导致有限类别错误替换。部分内部LightGBM超参尝试因长度不一致被跳过，其他路径继续产出输出；不能称所有子模型均成功。本次未静默修复、重跑或重评分。
- **CDC / QSAR主实验**：一种子二类拟合不满足要求，保留N/A，不以两次重复冒充三次均值。
- **TabClean**：历史截断/失败与后续七表受控正式轮分开；失败不填0，也不混入成功轮均值。
- **成本**：共享源拟合计一次，checkpoint复制不是独立冷训。请求累计时间、程序流程与启动排队范围不同，不计算统一跨硬件加速比。
- **复现范围**：本次执行文件/统计/表格核对与已有核心测试，没有重新执行全部GPU训练与模型实验。原始协议和固定输出用于复核。
