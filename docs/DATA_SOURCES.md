# Data sources and frozen inputs

Only datasets and conditions in `provenance/paper_scope.json` are included. Main repair and downstream input generation uses the pinned official UCI sources in `experiments/templates/`; feature/label roles, duplicate/entity grouping, fixed seeds and private references retain their original definitions. Downstream labels and clean holdout features are never method inputs.

- Real-error five-table inputs use `scripts/rebuild_real_inputs.py`, `experiments/paper_runs/real_dirty/public_data_sources.json` and the fixed `row_partition_config.json.gz`. Supply the pinned public author dirty/reference pairs; reconstructed files must match the original input SHA values. No additional artificial pollution is applied.
- The seven-table same-model comparison uses `scripts/rebuild_tabclean_inputs.py`; 21 prescribed inputs must match `input_fingerprints.json`.
- Digit70 uses `scripts/rebuild_controlled_inputs.py --study llm_digit70`; Retinopathy/Airfoil official archives and fixed public role IDs reconstruct all ten cases. Both arms are evaluated on the same inputs.
- Retinopathy robustness, Concrete robustness and sealed reuse are reconstructed locally by `scripts/rebuild_supplement_inputs.py` from the official UCI ZIPs. Download the pinned Concrete/Retinopathy/Airfoil sources with `scripts/reproduction_data.py download-uci`. Fixed seeds, pollution settings and expected input hashes are in `provenance/supplement_rebuild_specs.json`; it contains parameters and hashes, not saved data rows or answers. The constructor executes the archived original curator functions and checks all scientific input bytes. Fresh `private/source_provenance.json` records the new download/cache event and is explicitly rebound; it is not forced to match a historical timestamp or account path. The server's saved input/reference bundles are not distributed. Each reproducer generates the scorer-only `private/` references locally from the official source.
- Threshold uses fresh Retinopathy module-A skills and the corresponding frozen inputs, not historical skills substituted into a new run. Delta=0 must match the new A output byte for byte.

Input exports contain no old outputs, fitted skills, model budgets, service owners or score markers. `private/` evaluation references are curator/scorer-only; worker permissions must preserve that separation. Public data source licensing is not altered by this repository.
